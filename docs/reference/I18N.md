# 国际化 (i18n) 设计

## 1. 概述

Evolith 作为 SaaS 平台，需要支持多语言以服务全球用户。国际化涵盖：
- 界面文本翻译
- 日期/时间格式
- 数字格式
- 货币格式（未来计费场景）

## 2. 技术选型

| 方案 | 优点 | 缺点 |
|------|------|------|
| **react-i18next** | 成熟稳定、灵活 | 需手动配置 |
| lingui | Tree-shaking 友好 | 学习曲线较陡 |
| po-editor | 翻译管理方便 | 需要额外工具 |

**选择方案**：react-i18next（当前已实现）

## 3. 支持语言

| 语言代码 | 语言名称 | 本地名称 | 状态 |
|----------|----------|----------|------|
| zh-CN | 简体中文 | 中文 | ✅ 已实现 |
| en | English | English | ✅ 已实现 |
| ja | 日本語 | 日语 | ⬜ 规划中 |
| ko | 한국어 | 韩语 | ⬜ 规划中 |

## 4. 实现架构

### 4.1 目录结构

```
frontend/src/
├── lib/
│   └── i18n.ts              # i18n 初始化配置
├── locales/
│   ├── zh-CN.json           # 中文翻译
│   ├── en.json              # 英文翻译
│   ├── ja.json              # 日语翻译（规划）
│   └── ko.json              # 韩语翻译（规划）
├── app/
│   └── [locale]/
│       └── page.tsx         # 国际化路由（未来扩展）
└── components/
    └── LanguageSwitcher.tsx # 语言切换器
```

### 4.2 i18n 配置

```typescript
// lib/i18n.ts
import i18n from 'i18next';
import { initReactI18next } from 'react-i18next';
import LanguageDetector from 'i18next-browser-languagedetector';

i18n
  .use(LanguageDetector)
  .use(initReactI18next)
  .init({
    resources: {
      'zh-CN': { translation: zhCN },
      en: { translation: en },
    },
    fallbackLng: 'zh-CN',
    lng: getDefaultLanguage(),
    interpolation: { escapeValue: false },
    react: { useSuspense: false },
  });
```

### 4.3 语言检测优先级

```
1. URL 参数 (?lang=en)
2. localStorage (evolith-language)
3. 浏览器语言 (navigator.language)
4. 默认语言 (zh-CN)
```

## 6. 前端集成

### 6.1 基础用法

```tsx
import { useTranslation } from 'react-i18next';

function ToolPage() {
  const { t } = useTranslation();
  
  return (
    <div>
      <h1>{t('tools.title')}</h1>
      <button>{t('tools.createTool')}</button>
    </div>
  );
}
```

### 6.2 动态参数

```json
{
  "welcome": "欢迎, {name}!",
  "itemsCount": "共 {count} 个项目"
}
```

```tsx
// 使用
{t('welcome', { name: '张三' })}
{t('itemsCount', { count: 5 })}
```

### 6.3 复数支持

```json
{
  "item": "{{count}} 个项目",
  "item_plural": "{{count}} 个项目"
}
```

### 6.4 语言切换组件

```tsx
import { changeLanguage, languages } from '@/lib/i18n';

function LanguageSwitcher() {
  const handleChange = (e) => {
    changeLanguage(e.target.value);
  };
  
  return (
    <select onChange={handleChange}>
      {languages.map(lang => (
        <option key={lang.code} value={lang.code}>
          {lang.nativeName}
        </option>
      ))}
    </select>
  );
}
```

## 8. 翻译管理

### 8.1 翻译流程

```
1. 开发者在代码中使用 t('key') 
2. 运行 `bun run extract` 提取所有翻译键
3. 翻译人员翻译 locales/en.json
4. 提交翻译文件到仓库
```

### 8.2 提取命令

```json
// package.json
{
  "scripts": {
    "extract": "i18next 'src/**/*.{ts,tsx}' --output src/locales --",
    "compile": "i18next-compile"
  }
}
```

### 8.3 翻译服务集成（可选）

- **Lokalise** - 专业翻译管理平台
- **Crowdin** - 开源友好
- **Phrase** - 企业级

## 9. 最佳实践

### 9.1 代码规范

- ✅ 使用翻译键而非硬编码文本
- ✅ 保持翻译键语义清晰
- ✅ 避免在翻译中使用 HTML
- ✅ 正确处理复数形式
- ✅ 测试所有语言切换

### 9.2 性能优化

- ✅ 使用 React 懒加载
- ✅ 避免在组件外调用 t()
- ✅ 使用 nsSeparator 控制命名空间

### 9.3 SEO 考虑

- ✅ 为每种语言生成独立 meta 标签
- ✅ 使用 hreflang 指示替代版本
- ✅ 考虑静态页面预渲染
