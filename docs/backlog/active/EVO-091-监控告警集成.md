## Summary

- 类型：feature
- 优先级：P3
- 状态：Proposed
- 父 Epic：无

## Problem Or Outcome

后端已集成 `actix-web-prom` 和 `prometheus` metrics，但：
- 无告警规则定义
- 无 Grafana dashboard 配置
- 生产环境监控观测能力不完整

企业级平台需要实时监控和告警保障服务可用性。

## Goal And Non-Goals

**目标**：
- 提供 Prometheus alerting rules 基线（健康检查失败、错误率、延迟阈值）
- 提供 Grafana dashboard JSON 配置示例
- 文档化监控部署和接入步骤

**不做**：
- 不部署 Grafana/Prometheus 实例（由运维团队决定）
- 不引入复杂 SLI/SLO 体系（可后置）
- 不改变现有 metrics 命名原则

## Dependencies And Blockers

- 需要实际生产环境验证（可在 dev 环境模拟）
- 可与 EVO-030 CI/CD 协调部署流程

## Governing ADRs, Specs Or Decisions

- 已有 `actix-web-prom 0.10.0` + `prometheus 0.14.0` metrics 基线

## Acceptance Criteria

- [ ] `deploy/monitoring/` 目录包含 Grafana dashboard JSON
