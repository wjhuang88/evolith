## Problem Or Outcome

当前测试存在明显盲区：
1. **service-audit crate 零测试**：审计是企业级平台核心能力，缺乏测试覆盖风险高
2. **PostgreSQL repository 无集成测试**：8 个 repo 集成测试仅覆盖 SQLite，生产主路径 PostgreSQL 未验证
3. **前端单元测试缺失**：frontend 目录无测试文件，核心组件和 store 未验证

这与 EVO-053（测试盲区补齐）相关但范围更具体，聚焦可量化覆盖率提升。

## Goal And Non-Goals

**目标**：
- service-audit 至少 5 个单元测试覆盖核心逻辑
- PostgreSQL repository 至少 1 个基础集成测试（可与 SQLite 共享测试逻辑）
- 前端 authStore 至少 3 个单元测试验证状态管理逻辑

**不做**：
- 不追求 100% 覆盖率（成本过高）
- 不引入复杂 E2E 测试框架（与 EVO-053 协调）
- 不为 trivial getter/setter 写测试

## Dependencies And Blockers

- PostgreSQL 测试需要 CI 环境（EVO-030 已建立 CI，可复用）
- 可与 EVO-053 协调，避免重复投入

## Governing ADRs, Specs Or Decisions

- EVO-053 已识别测试盲区

- [ ] infra/tests/ 新增至少 1 个 PostgreSQL-specific 或 DB-shared integration test
