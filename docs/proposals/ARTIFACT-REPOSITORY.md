# 规划: 制品仓库

> 来源：原需求文档 2.4
> 状态：远期规划

## 功能描述

提供多语言预编译依赖库管理，面向大模型优化文档。

## 功能列表

| 功能ID | 功能名称 | 描述 |
|--------|----------|------|
| F1.4.1 | 包管理 | 支持 npm / crate / pypi 包 |
| F1.4.2 | 预编译 | 提供编译好的二进制 |
| F1.4.3 | LLM 文档 | 面向大模型的 API 文档 |
| F1.4.4 | 版本管理 | 语义化版本控制 |

## 进入条件

- MCP tool、Skill、CLI interface 三条主线完成 P0/P1 闭环。
- Storage 能力稳定。
- CLI 具备基础 push/pull 能力。

## 暂缓原因

当前产品核心价值尚未完全闭环，制品仓库会引入新的包索引、存储、安全扫描和兼容性复杂度，因此保持远期规划。
