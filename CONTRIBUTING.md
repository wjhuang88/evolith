# Contributing to Evolith

Thank you for your interest in contributing to Evolith.

Evolith is an open-source project distributed under the GNU Affero General Public License v3.0 only (`AGPL-3.0-only`) and is also intended to support a separate commercial licensing path.

That dual-licensing model affects how external contributions can be accepted.

## Current contribution policy

Bug reports, design discussions, documentation feedback, reproducible test cases, and other non-code contributions are welcome through GitHub issues and pull requests.

For **substantive third-party code contributions**, the project must ensure that the Evolith project owner receives sufficient rights to maintain both the AGPL open-source distribution and future commercial licensing.

Until a formal Contributor License Agreement (CLA) workflow is published and operational:

- maintainers may review external code contributions;
- maintainers may ask contributors to hold or revise a pull request;
- substantive third-party code will not be merged if doing so could prevent the project owner from commercially relicensing Evolith in the future.

This temporary gate is intentional. It avoids creating fragmented copyright ownership before the contribution agreement is ready.

## What the future CLA will preserve

The planned CLA is expected to:

- let contributors retain copyright in their contributions;
- grant the Evolith project owner a broad, non-exclusive right to use, modify, distribute, sublicense, and relicense accepted contributions;
- include an appropriate patent grant for contributed work;
- confirm that the contributor has the right to submit the contribution;
- preserve the project's ability to distribute the open-source edition under the AGPL while also offering commercial licenses.

The final CLA text will be published before it is required for external code contributions.

## Licensing of accepted contributions

Unless explicitly agreed otherwise in writing, accepted contributions that become part of the open-source Evolith codebase will be distributed as part of Evolith under `AGPL-3.0-only`.

Submitting a pull request by itself does not grant a commercial license to Evolith, nor does it change the license of the existing Evolith codebase.

## Third-party code

Do not submit code, assets, models, generated material, or other content unless you have the right to contribute it under terms compatible with Evolith's licensing model.

Any contribution that incorporates third-party material must identify the source and applicable license. Maintainers may reject dependencies or copied material whose license is incompatible with the project or its commercial licensing path.

## Developer Certificate of Origin

The project may additionally use Developer Certificate of Origin (DCO) sign-off for provenance tracking. DCO sign-off and a CLA serve different purposes: a DCO records contribution provenance, while the CLA provides the additional rights needed for the project's dual-licensing model.

Until the repository explicitly enables a DCO or CLA workflow, do not assume that `Signed-off-by` alone is sufficient for merging substantive third-party code.

## Questions

For licensing-sensitive contributions, open an issue in the canonical Evolith repository before investing in a large implementation.
